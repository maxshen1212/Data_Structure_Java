# Computing Complaxity

## Time / Space

Big-O  => worst case of Time complaxity
  * input = arbitraily large

Constant Time      =>  O( 1 )
Logarithmic Time   =>  O( logn )
Linear Time        =>  O( n )
Linearithmic Time  =>  O( nlogn )
Quadric Time       =>  O( n^2 )
Cubit Time         =>  O( n^3 )
Exponential Time   =>  O( b^n ) b>1
Factorial Time     =>  O( n! )
