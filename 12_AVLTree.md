# Balnanced Binary Search Tree
rotation + balanced + update
The rotation may be:
Right Rotation, Left Rotation, and Double Rotation

Insert, Delete, Remove, Search = O(log n) in worst case

## AVL Tree
BalancedFactor(node) = H(node.left) - H(node.right)
-1 <= BalancedFactor <= 1

## Red Black Tree
longest path <= shortest path * 2
