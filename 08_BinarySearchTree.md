## Binary Search Tree (BST)
A BST is a binary tree where the left child is less than the parent and the right child is greater than the parent

Insert, Delete, Remove, Search = O(log n) in average
Insert, Delete, Remove, Search = O(n) in worst case


1. Pre-order traversal is used to create a copy of the tree
2. In-order traversal of a BST will yield a sorted sequence of values!!! (increaseing number)
3. Post-order traversal is used to delete the tree
